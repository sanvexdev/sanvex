# Gmail

**Package:** `sanvex/gmail`  
**Driver id:** `gmail`  
**Auth:** `oauth2` only (default: `oauth2`)

Install Sanvex [core and CLI](../../getting-started/installation) before adding this driver.

```bash
composer require sanvex/gmail
```

See [Setup](./setup) and [Resources](./resources).
