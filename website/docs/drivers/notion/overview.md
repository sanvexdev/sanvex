# Notion

**Package:** `sanvex/notion`  
**Driver id:** `notion`  
**Auth:** `api_key`, `oauth_2` (default: `api_key`)

Notion uses `oauth_2` (underscore) in driver code, not `oauth2`.

```bash
composer require sanvex/notion
```
