# GitHub

**Package:** `sanvex/github`  
**Driver id:** `github`  
**Auth:** `api_key`, `oauth2` (default: `api_key`)

Install Sanvex [core and CLI](../../getting-started/installation) before adding this driver.

```bash
composer require sanvex/github
```
